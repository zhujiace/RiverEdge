Dual-tail interpretation for exit layer k:
  shared prefix: model.layers[0:k]
  FP tail:       model.layers[k:32] + model.norm
  PTQ tail:      model.exit_modules.0[k:32] + model.exit_modules.1[k-1]

Index note:
  exit_layer k is 1-indexed. For k=3, prefix uses layers 0,1,2;
  PTQ tail uses exit_modules.0 indices 3..31.
