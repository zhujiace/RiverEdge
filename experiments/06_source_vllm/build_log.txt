## Limitation

This P5 baseline uses official precompiled native extensions with editable Python source. It is ready for Python-level vLLM modifications. If RiverEdge needs changes in C++/CUDA/Rust extensions, run a separate full local native build with `VLLM_USE_PRECOMPILED=0`.
